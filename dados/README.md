# Dados de validação

Cada arquivo começa com um cabeçalho que diz de onde vêm os dados: referência
completa (como no PDF do curso), tabela ou figura de origem, quem transcreveu
ou de onde foi baixado, e a licença quando o arquivo for baixado.

Nenhum valor é digitado de memória. Arquivos ainda não preenchidos trazem só o
cabeçalho e a marcação `PREENCHER`.
